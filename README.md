# CS-330 Computer Graphics and Visualization

## Project Overview

This repository contains my portfolio artifacts from CS-330 Computer Graphics and Visualization. For my final project, I developed a 3D scene based on a reference image of a house. I recreated the scene using OpenGL and built the environment from multiple 3D objects representing features such as the house, garage, door, windows, chimney, grass, and surrounding environment. Throughout the course, I gradually improved the scene by applying transformations, textures, camera controls, lighting, and other graphics techniques.

The repository includes the completed 3D Scene ZIP file and my Design Decisions document. Together, these artifacts demonstrate the design and development process I followed to transform a 2D reference image into an interactive 3D environment.

## How Do I Approach Designing Software?

### What new design skills has your work on the project helped you to craft?

This project helped me improve my ability to break a larger visual design into smaller and more manageable components. Instead of thinking about the house as one complicated object, I learned to identify basic shapes that could be combined, scaled, positioned, and rotated to create the complete scene. I also gained experience thinking about how textures, lighting, object placement, and camera perspective work together to create a more realistic representation.

### What design process did you follow for your project work?

I followed an incremental design process throughout the project. I began with the reference image and identified the major objects needed to recreate it. I first created the basic geometry and arranged the objects along the X, Y, and Z axes. As the course progressed, I added camera navigation, textures, and lighting. I tested the scene after each major change and adjusted object positions, scales, textures, lighting values, and camera settings until the scene looked and behaved as intended.

### How could tactics from your design approach be applied in future work?

The same approach can be applied to future software projects by breaking complicated problems into smaller pieces and completing them one step at a time. Creating the basic functionality first and then gradually adding more advanced features makes development easier to manage. This also makes it easier to identify problems because each new feature can be tested before moving on to the next one.

## How Do I Approach Developing Programs?

### What new development strategies did you use while working on your 3D scene?

One important development strategy I used was separating repeated tasks into reusable functions. Rather than writing all of the rendering logic in one large section of code, I used functions to organize transformations, textures, lighting, and the rendering of individual objects. I also learned how different parts of the graphics pipeline work together, including shaders, textures, meshes, camera controls, and lighting calculations.

### How did iteration factor into your development?

Iteration was an important part of developing my 3D scene. The project was completed through several milestones, so I was able to build the scene gradually instead of trying to complete everything at once. I frequently ran the program after making changes and visually inspected the results. When an object's position, texture, lighting, or camera view did not look correct, I adjusted the code and tested it again. This repeated process helped the scene become more polished with each milestone.

### How has your approach to developing code evolved throughout the milestones, which led you to the project's completion?

At the beginning of the course, I focused mainly on getting basic objects to appear correctly. As I progressed through the milestones, I became more comfortable organizing the scene and understanding how different graphics components interacted with one another. I moved from simply creating shapes to controlling transformations, navigating the scene with a virtual camera, applying textures, and implementing lighting. I also became more aware of code organization, reusable functions, descriptive comments, and testing changes individually. By the final project, I was able to combine these techniques into one complete 3D scene.

These experiences will help me approach future software development projects in a more organized and systematic way.
